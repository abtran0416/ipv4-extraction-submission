## Confirmed corrections and automated testing

The final changes were:

- Reject an octet when a fourth digit is encountered and a port when a sixth digit is encountered. This prevents their counters from growing without a limit. The full candidate is still skipped on failure.
- Change the input prompt to `Enter a string (or 'END' to quit):`.
- Print `Invalid input: no valid IPv4 address found` when extraction fails.

To repeat the automated checks:

```sh
python3 run_tests.py
```
